# AI-Talk

주제를 던지면 AI 참가자들이 실제 토론처럼 말을 주고받는 프로그램입니다. 내 PC에서 혼자 씁니다.

설계와 현재 상태는 [docs/design.md](docs/design.md)에, 2026-11-18에 고친 내용은 [docs/fix_log.md](docs/fix_log.md)에 있습니다.

## 처음 한 번

Python 3.13과 Node.js가 필요합니다.

1. `installer.bat`을 실행합니다. 파이썬 패키지와 화면 패키지를 설치하고 화면을 빌드합니다.
2. 설치가 끝나면 `.env`가 메모장으로 열립니다. 어느 AI를 쓸지와 API 키를 채우고 저장합니다. 키는 이 파일에만 두며, 이 파일은 git에 올라가지 않습니다.

| `AITALK_PROVIDER` | 쓰는 곳 | 필요한 값 |
|---|---|---|
| `claude` | 집 | `ANTHROPIC_API_KEY` |
| `pgpt` | 회사 OA망 | 키(`PGPT_API_KEY` 또는 `API_KEY`)와 코드(`PGPT_SYSTEM_CODE`, `PGPT_EMPNO`, `EMPLOYEE_NO` 가운데 하나) |
| `mock` | 화면만 확인 | 없음. AI를 부르지 않습니다 |

`AITALK_PROVIDER`는 처음에 쓸 AI입니다. 실행한 뒤에는 설정 화면에서 바꿀 수 있습니다.

P-GPT의 값은 적힌 순서대로 찾습니다. 같은 묶음 안에서는 `.env`를 먼저 다 보고, 거기에 없을 때만 Windows 환경 변수를 봅니다. 빈 값은 건너뜁니다. `COMPANY_CODE`는 비워 두면 `30`입니다.

## 실행

`ai-talk.bat`을 실행하면 서버가 켜지고 실행 창에 접속 주소가 나옵니다. 브라우저는 자동으로 열리지 않으니 http://127.0.0.1:8765 를 직접 엽니다. 화면 소스가 바뀌었을 때만 자동으로 다시 빌드합니다.

실행 창(검은 창)에서 쓰는 키:

| 키 | 동작 |
|---|---|
| `R` | Enter 없이 바로 하드 리셋합니다. 서버를 끝내고 `.env`와 코드를 다시 읽어 켭니다. 한글 입력 상태(`ㄱ`)에서도 됩니다. 누르고 있어도 한 번만 처리합니다 |
| `Ctrl+C` | 서버와 실행 창을 끝냅니다 |

- 하드 리셋을 하면 진행 중인 토론은 끊깁니다. 저장된 토론 기록과 페르소나는 그대로입니다. 브라우저는 새로고침해야 합니다.
- 코드 오류로 서버가 꺼져도 실행 창은 남습니다. 고친 뒤 `R`을 누르면 다시 켭니다.
- **켜기 전과 다시 켜기 전에, 설정된 포트(기본 8765)를 듣고 있는 프로세스를 모두 끝냅니다.** 다른 프로그램이 같은 포트를 쓰고 있어도 끝내므로, 겹친다면 `.env`의 `AITALK_PORT`를 다른 번호로 바꿔 주세요.
- 켤 때 브라우저를 자동으로 열고 싶으면 `ai-talk.bat` 안의 실행 줄 끝에 `--open`을 붙입니다 (`python scripts\launch_aitalk.py --open`). 그때도 처음 한 번만 엽니다.

## 화면에서 알아 둘 것

- **참가자 구성.** "자동 생성"은 주제에 맞는 인물을 AI가 새로 만듭니다. 이름은 "웹툰 작가", "저작권 변호사"처럼 어떤 인물인지 알 수 있는 호칭으로 짓습니다. "보관함에서 구성"은 새로 만들지 않고 페르소나 보관함의 인물로 구성합니다. 누르면 목록이 열리고, 맨 위의 "자동선택"을 누르면 주제에 어울리는 사람을 AI가 골라 그 사람의 입장만 주제에 맞춥니다. 목록에서 몇 명을 먼저 체크해 두면 그 사람들은 그대로 넣고 남은 자리만 AI가 고릅니다. 카드의 보관함 아이콘으로 한 명씩 직접 고를 수도 있습니다.
- **기본 인물.** 보관함에는 유명 경영자, 철학자, 역사 인물 22명이 들어 있습니다. 널리 알려진 생각과 말투를 본뜬 AI의 재현이며, 실제 그 사람의 발언이 아닙니다.
- **전체화면.** 어느 화면에서든 마우스 우클릭으로 전체화면이 되고, 다시 우클릭하거나 `Esc`를 누르면 풀립니다. 그래서 마우스 우클릭 메뉴는 뜨지 않습니다. 키보드의 메뉴 키와 `Shift+F10`은 그대로 메뉴를 엽니다.
- **각주.** 발언에 들어 있는 링크는 `[1]`, `[2]` 같은 번호로 바뀝니다. 번호를 누르면 그 자료가 새 탭에서 열립니다. 같은 자료는 누가 언제 인용해도 토론 전체에서 같은 번호입니다.
- **출처 목록.** 출처가 있는 발언은 마지막 문장 옆에 링크 아이콘이 붙습니다. 누르면 사이트별로 묶인 목록이 펼쳐지고, 다시 누르면 접힙니다. 옆 패널의 "출처" 탭에는 토론 전체의 출처가 같은 번호로 모입니다.
- **출처 이름.** 목록을 펼치면 서버가 그 페이지를 직접 받아 브라우저 탭에 뜨는 제목으로 이름을 바꿉니다. 페이지를 받지 못하면 풀어 쓴 주소를 그대로 보여 줍니다. 공개 웹 주소만 조회하고, 접어 둔 목록은 조회하지 않습니다.

## 같은 망의 다른 PC에서 접속

기본으로 켜져 있습니다. `ai-talk.bat`을 실행하면 실행 창과 설정 화면에 접속 주소(`http://이PC의IP:8765`)가 나옵니다.

- 처음 켤 때 Windows 방화벽이 물으면 "액세스 허용"을 눌러야 합니다.
- 로그인이 없습니다. `.env`에 `AITALK_ACCESS_CODE=원하는코드`를 넣으면 다른 PC에서 들어올 때 그 코드를 묻습니다. 넣지 않으면 같은 망의 누구나 들어와 내 AI 키로 토론을 돌리고 기록을 지울 수 있습니다.
- 이 PC에서만 쓰려면 `.env`에 `AITALK_HOST=127.0.0.1`을 넣습니다.

## 쓸 AI 바꾸기

설정 화면의 AI 표에서 "이걸로 바꾸기"를 누르면 바로 바뀌고, 마지막 선택을 기억합니다. 키는 `.env`(또는 Windows 환경 변수)에 있어야 합니다. 키가 없으면 표에 어떤 변수가 필요한지 나옵니다. 키 값은 화면에 보여 주지 않습니다.

## 회사에서 P-GPT를 쓸 때

P-GPT는 회사 OA망에서만 연결됩니다. 이 저장소의 P-GPT 코드는 집에서 가상 API로만 시험했으므로, 회사에서 먼저 점검 스크립트를 돌려 주세요.

```bash
python scripts/check_pgpt.py
```

끝에 나오는 표에서 "안 됨"인 항목이 있으면 그 표를 그대로 전달해 주세요.

상태 유지, 판단 분리, 웹 검색, 자동 압축, 기억 복구를 실제 호출로 보려면 아래 스크립트를 씁니다. `--execute`가 없으면 무엇을 확인하는지만 보여 주고 P-GPT를 부르지 않습니다.

```bash
python scripts/check_pgpt_context.py --execute
```

## 개발

```bash
python -m pytest apps/server/tests -q
```

엔진 테스트가 느려 전체는 5분 가까이 걸립니다.

화면 쪽 테스트는 `apps/web`에서 실행합니다. TypeScript를 바로 읽는 Node.js가 필요합니다.

```bash
npm test
```

화면을 고치면서 볼 때는 서버(8765)를 띄운 채로 `apps/web`에서 `npm run dev`를 실행하고 http://127.0.0.1:5180 을 엽니다. 각주와 출처, 전체화면의 동작은 같은 개발 서버의 http://127.0.0.1:5180/tests/citations.browser.html 에서 가상 기록으로 확인할 수 있습니다. 이 페이지는 서버나 AI를 부르지 않습니다.
